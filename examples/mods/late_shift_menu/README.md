# Late Shift Menu

**Tier 1 — data modder.** Everything here is JSON. No engine, no editor, no build step.

Three products and a recipe that uses two of them. The recipe is unlocked by
`base:food_service`, and the products come from `base:nightfreight_discount` — the cheap
supplier, which is cheap for a reason.

```bash
tools/validate_mod.sh examples/mods/late_shift_menu
```
